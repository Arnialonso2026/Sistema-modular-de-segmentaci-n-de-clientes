## Página 11 - Aprendizaje no supervisado

### Definición

El aprendizaje no supervisado es una rama del Machine Learning en la que los algoritmos analizan y procesan **datos que no tienen etiquetas ni respuestas predefinidas**.

A diferencia del aprendizaje supervisado, donde el algoritmo sabe lo que busca, este modelo analiza la información bruta para descubrir:

- Patrones.
- Estructuras internas.
- Relaciones ocultas.

Todo esto se descubre automáticamente a partir de los datos.

## Página 15 - Agrupamiento (Clustering)

### Definición

El agrupamiento divide los datos en grupos o **clústeres** que comparten características similares de forma natural.

Su objetivo es la **segmentación**:

- Junta los elementos que se parecen entre sí.
- Separa los elementos que son diferentes.

### Algoritmos comunes

#### 1. K-Means - Particionamiento

Divide los datos en un número fijo de **K clústeres** definidos previamente.

Busca centros llamados **centroides** para agrupar puntos, especialmente cuando los grupos pueden representarse aproximadamente como agrupaciones compactas o esféricas.

#### 2. Clustering Jerárquico

Construye una **jerarquía de grupos**.

Suele visualizarse mediante un **dendrograma**.

Puede operar fusionando o dividiendo datos en distintos niveles.

#### 3. DBSCAN - Basado en densidad

Agrupa puntos según la **densidad del espacio**.

Ventajas mencionadas:

- Puede detectar formas irregulares.
- Puede marcar puntos aislados como **ruido**.

#### 4. Modelos de Mezcla Gaussiana - GMM

Asume que los datos provienen de una mezcla de varias **distribuciones gaussianas o normales**.

### Ejemplo del PDF

Segmentar a los clientes de un banco en **perfiles de gasto**, por ejemplo:

- Viajeros.
- Ahorradores.
- Compradores compulsivos.

El objetivo sería ofrecer productos personalizados a cada grupo.

## Página 16 - Reglas de asociación

### Objetivo

Descubrir relaciones ocultas en los datos.

Busca patrones del tipo:

> "Si ocurre A, es muy probable que ocurra B".

### Algoritmos comunes

#### 1. Apriori

Utiliza un enfoque descrito como **"fuerza bruta inteligente"**.

Parte de la idea de que si un conjunto de elementos es frecuente, entonces todos sus subconjuntos también deben ser frecuentes.

#### 2. FP-Growth - Frequent Pattern Growth

Es presentado como una evolución y alternativa eficiente a Apriori.

Características:

- No genera combinaciones candidatas una por una.
- Comprime la base de datos en una estructura de árbol llamada **FP-Tree**.
- Solo necesita escanear la base de datos dos veces.
- Esto lo hace más rápido en grandes volúmenes de datos.

#### 3. ECLAT - Equivalence Class Transformation

A diferencia de Apriori y FP-Growth, que buscan de manera horizontal registro por registro, **ECLAT realiza una búsqueda vertical**.

Se enfoca en los **IDs de las transacciones** donde aparece cada producto.

Acelera el cálculo mediante operaciones de **intersección de conjuntos**.

### Ejemplo del PDF

Detectar que quienes compran **pañales los viernes por la tarde** también suelen comprar **cerveza**.

## Página 17 - Reducción de dimensionalidad

### Objetivo

La reducción de dimensionalidad busca la **simplificación**.

Cuando un conjunto de datos tiene cientos de columnas o variables, el proceso lo "comprime" a un conjunto menor de variables importantes para que:

- Los modelos visuales sean más manejables.
- Los cálculos sean más rápidos.
- El procesamiento sea más eficiente.
- Se conserve la esencia principal de la información.

### Algoritmos comunes

### A. Métodos lineales

#### PCA - Análisis de Componentes Principales

Transforma las variables originales en un nuevo conjunto de variables **incorrelacionadas** llamadas **componentes principales**.

Los componentes se ordenan de mayor a menor según la cantidad de información o **varianza** retenida.

#### LDA - Análisis Discriminante Lineal

A diferencia de PCA, presentado como puramente no supervisado, LDA se usa a menudo de forma supervisada.

Reduce dimensiones buscando **maximizar la separación entre clases o categorías ya conocidas**.

### B. Métodos no lineales - Manifold Learning

#### t-SNE - t-Distributed Stochastic Neighbor Embedding

- Mapea datos de cientos de dimensiones a solo **2 o 3 dimensiones**.
- Busca mantener elementos similares cerca y elementos diferentes lejos.
- Es útil para visualizar agrupamientos.
- Según el material, no se recomienda para entrenar otros modelos porque puede deformar las distancias globales.

#### UMAP - Uniform Manifold Approximation and Projection

Se presenta como una alternativa moderna a t-SNE.

Ventajas destacadas:

- Es más rápido.
- Maneja mejor conjuntos de datos muy grandes.
- Preserva mejor la estructura global de los datos.

### Ejemplo del PDF

Comprimir los miles de píxeles de una imagen de reconocimiento facial a unos pocos **rasgos clave** o componentes principales.

## Página 18 - Algoritmo K-Means

### Definición

K-Means es uno de los algoritmos de aprendizaje no supervisado más populares y utilizados.

Su objetivo principal es **particionar un conjunto de datos en K grupos o clústeres distintos**.

Cada dato pertenece al grupo cuyo **centroide** está más cerca.

### Descripción del diagrama

El gráfico muestra dos paneles:

1. **Unlabelled Data / Datos sin etiquetar**
   - Se ven varios grupos naturales de puntos grises, pero no tienen categorías.

2. **Labelled Data / Datos agrupados**
   - Después de aplicar K-Means aparecen tres grupos diferenciados por color.
   - Cada grupo tiene un símbolo **X** que representa su **centroide**.

El flujo visual indica que K-Means toma datos sin etiquetas y genera agrupaciones basadas en la distancia a los centroides.

---

## Página 19 - ¿Cómo funciona el algoritmo K-Means?

El proceso se explica en cuatro pasos.

### 1. Elegir K

Se define cuántos grupos se desean encontrar.

Ejemplo conceptual: si se necesitan 3 zonas de reparto, entonces **K = 3**.

### 2. Asignación

El algoritmo coloca **K puntos iniciales**, llamados **centroides**, de forma aleatoria.

Luego agrupa cada dato con el centroide más cercano.

La cercanía suele medirse utilizando **distancia euclidiana**.

### 3. Actualización

Para cada grupo se calcula el centro real de los puntos asignados.

Después, el centroide se mueve a esa nueva posición.

### 4. Repetición

El proceso de asignación y actualización se repite hasta que los centroides ya no se mueven.

### Distancia euclidiana

La distancia euclidiana es la longitud del segmento de recta que une a dos puntos en un espacio geométrico.

Representa la distancia más corta y directa entre ellos.

## Página 24 - ¿Qué es una Red Neuronal Artificial (ANN)?

### Definición

Una Red Neuronal Artificial o **ANN (Artificial Neural Network)** es un modelo computacional inspirado en la estructura biológica del cerebro humano.

Está compuesta por unidades de procesamiento llamadas **neuronas matemáticas** interconectadas entre sí.

### Estructura estándar

#### 1. Capa de Entrada - Input Layer

Recibe las características numéricas crudas.

**Ejemplo del PDF:** píxeles de una cámara.

#### 2. Capas Ocultas - Hidden Layers

Extraen patrones abstractos mediante:

- Multiplicación de los datos por **pesos (weights)**.
- Aplicación de **funciones de activación**, por ejemplo **ReLU**.

#### 3. Capa de Salida - Output Layer

Entrega la decisión probabilística final.

Para clasificación, puede utilizar funciones de activación como **Softmax**.

---

## Página 25 - Hiperparámetros en la Red Neuronal Artificial

### Definición

Los **hiperparámetros** son variables de configuración externa que se definen manualmente **antes de iniciar el entrenamiento**.

Controlan cómo aprende el modelo.

### Diferencia entre hiperparámetros y parámetros

#### Hiperparámetros

- Se fijan antes del entrenamiento.
- Son definidos por el programador o científico de datos.
- Configuran la forma en que el modelo aprende.

#### Parámetros del modelo

Ejemplos:

- Pesos.
- Sesgos.

Estos parámetros son aprendidos y ajustados automáticamente por la red a partir de los datos durante el entrenamiento.

### Descripción del gráfico

La diapositiva compara dos procesos:

- **Hyperparameters tuning → Hyperparameters**: engranajes verdes representan la configuración externa del modelo.
- **Model training → Model Parameters**: engranajes rojos representan el entrenamiento que produce o ajusta los parámetros internos.

El objetivo visual es separar claramente lo que configura el humano de lo que aprende automáticamente la red.

## Página 26 - Tipos de hiperparámetros

### A. Hiperparámetros de arquitectura

Definen la estructura física y capacidad de la red.

- Número de capas ocultas.
- Número de neuronas por capa.
- Tipos de funciones de activación, por ejemplo:
  - ReLU.
  - Sigmoide.

### B. Hiperparámetros de entrenamiento

Controlan cómo avanza la optimización de la red.

#### Tasa de aprendizaje - Learning Rate

Define qué tan grandes son los pasos que da el optimizador al corregir los errores.

#### Tamaño del lote - Batch Size

Cantidad de muestras que se procesan antes de actualizar los pesos de la red.

#### Épocas - Epochs

Cantidad de veces que el conjunto completo de datos de entrenamiento pasa a través de la red.

### C. Hiperparámetros de regularización

Sirven para evitar que la red memorice los datos en exceso, es decir, evitar **sobreajuste u overfitting**.

Ejemplos:

- **Dropout:** desconexión aleatoria de neuronas durante el entrenamiento.
- Penalizaciones como regularización **L1** o **L2**.

## Página 27 - ¿Qué es una época en una red neuronal artificial?

### Definición

Una **época (epoch)** es un ciclo completo de entrenamiento en el que la red neuronal procesa la totalidad del conjunto de datos de entrenamiento una vez.

### Una pasada completa

Durante una época, cada muestra de los datos de entrenamiento pasa por la red para que esta ajuste sus parámetros internos:

- Pesos.
- Sesgos.

### Lotes e iteraciones

Como el conjunto de datos puede ser muy grande, se divide en partes más pequeñas llamadas **lotes (batches)**.

El número de lotes necesarios para completar una época depende del tamaño de cada lote.

### Múltiples épocas

Una sola pasada rara vez es suficiente para aprender patrones complejos.

Por ello, el entrenamiento utiliza múltiples épocas para reducir gradualmente el error de predicción.

### Iteración - Iteration

Una iteración es el paso en el que la red procesa **un solo lote de datos**.

Una época contiene varias iteraciones.

---

## Página 28 - ¿Qué es una función de activación?

### Definición

En una red neuronal, una función de activación es una ecuación matemática que se aplica a la salida de cada neurona para determinar si debe "activarse" o transmitir información.

En términos sencillos, funciona como un **interruptor matemático** que decide:

- Si una neurona debe transmitir información.
- Con qué intensidad debe hacerlo.

### ¿Cómo actúa en la red neuronal?

Su objetivo principal es introducir **no linealidad** en el modelo.

Sin una función de activación, una red neuronal sería solo una gran combinación de:

- Sumas.
- Multiplicaciones lineales.

Aunque tuviera muchas capas, se comportaría de forma equivalente a un modelo lineal simple y tendría dificultades para aprender patrones complejos como:

- Imágenes.
- Texto.
- Audio.

## Página 29 - Proceso interno de una neurona

### Texto principal

Cada neurona de la red, sin importar en qué capa se encuentre, repite de forma similar estos pasos:

1. Recibe entradas.
2. Multiplica las entradas por pesos matemáticos.
3. Suma los resultados.
4. Añade un sesgo.
5. Pasa el resultado por una función de activación.
6. Produce una salida.

### Descripción del diagrama

El gráfico representa una neurona matemática.

Elementos visibles:

- **Entradas:** varios valores de entrada, por ejemplo x₁, x₂, xₙ.
- **Pesos:** cada entrada se conecta con la neurona mediante un peso.
- **Bias / Sesgo:** se añade un término adicional.
- **Suma ponderada:** se muestra una operación equivalente a una suma del tipo Σ(wᵢxᵢ) más el sesgo.
- **Función de activación f(z):** transforma la suma ponderada.
- **Salida:** resultado final de la neurona.

### Representación matemática conceptual derivada del diagrama

```text
z = (w1*x1 + w2*x2 + ... + wn*xn) + b
salida = f(z)
```

Donde:

- `x` = entradas.
- `w` = pesos.
- `b` = sesgo o bias.
- `f` = función de activación.

Esta fórmula expresa en texto lo que aparece gráficamente en la diapositiva.

## Página 33 - Cuándo usar ReLU y cuándo cambiarla: Escenario B

### Escenario B: "El cerebro se congela" - Neurona muerta / Die-Hard ReLU

### Problema planteado

Se está entrenando una red neuronal profunda para reconocer rostros.

A partir de la época 4:

- La precisión se estanca.
- El error deja de bajar.
- Al revisar el modelo se descubre que aproximadamente el **70 % de las neuronas ocultas** producen 0 de forma permanente.
- Esto ocurre porque reciben señales negativas recurrentes.

El material indica que estas neuronas han "muerto".

### Decisión

Cambiar ReLU por:

- **Leaky ReLU**, o
- **ELU**.

### Razón

Con una configuración similar a:

```python
layers.LeakyReLU(alpha=0.01)
```

los valores negativos no se destruyen completamente convirtiéndose en cero.

En su lugar, se conserva una pequeña pendiente decimal.

Según el material, esto permite que las neuronas sigan actualizando sus pesos y que el modelo continúe aprendiendo, por ejemplo, texturas complejas de la piel.

## 1. Aprendizaje no supervisado


Tipos mencionados en la sesión:

- Reducción de dimensionalidad.

---

## 2. Clasificación vs. Clustering

### Clasificación

```text
Tipo: Supervisado
Entrada: Datos + etiquetas conocidas
Objetivo: Predecir una clase conocida
Ejemplo: Fraude / No fraude
```

### Clustering

```text
Tipo: No supervisado
Entrada: Datos sin etiquetas
Objetivo: Descubrir grupos naturales
Criterio frecuente: Similitud / distancia
```

Para el caso de las coordenadas de clientes sin zona conocida, la sesión conduce al uso de **clustering**.

---

## 3. K-Means

### Propósito

Separar los datos en `K` grupos.

### Conceptos

- `K`: cantidad de clústeres.
- `centroide`: centro representativo de un clúster.
- `distancia euclidiana`: medida utilizada para determinar qué centroide está más cerca de un punto.
- `iteración`: repetición del proceso de asignar y recalcular centroides.

### Flujo

```text
1. Elegir K
2. Inicializar K centroides
3. Asignar cada punto al centroide más cercano
4. Recalcular el centroide de cada grupo
5. Repetir 3 y 4
6. Finalizar cuando los centroides dejan de cambiar
```

### Aplicaciones mencionadas

- Segmentación de clientes.
- Sistemas de recomendación.
- Detección de anomalías y fraudes.
- Organización de documentos o información.
